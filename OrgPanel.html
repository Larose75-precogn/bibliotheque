Comment récupérer ces identifiants
  1. Crée un compte sur enablebanking.com (juste ton email, pas de mot de passe).
  2. Va dans Applications et crée une nouvelle application.
  3. Choisis SANDBOX pour tester (comptes factices) — ne coche "production" ci-dessous QUE si Enable Banking t'a explicitement donné un accès production pour connecter de vraies banques.
  4. Pour la clé, choisis l'option "Generate in the browser… export private key" — ça te donne d'un coup l'App ID ET la clé privée à coller ci-dessous.
Powens non configuré
Étape 1/6
Crée un compte sur la console Powens (ex-Budget Insight) et renseigne les infos de ta société (une seule fois) — si tu as déjà un compte, connecte-toi simplement.
Crée un domaine : choisis un nom (ex. le nom de ton organisation), il devient automatiquement …-sandbox.biapi.pro — note ce nom, c'est ton Domaine plus bas (sans le .biapi.pro).
Dans le menu de gauche du domaine, va dans « Applications » → « Nouvelle application cliente ».
Nom : le nom de ton organisation. URIs de redirection : colle EXACTEMENT https://structory.ai/ (avec le « s » et le / final, sinon la connexion échouera). Enregistre.
Le Client ID s'affiche directement ; clique sur « Afficher » à côté du Client secret pour le révéler — copie les deux, tu vas les coller plus bas.
Besoin de les retrouver plus tard ? Console Powens → Domaines → ton domaine → Applications → clique sur le NOM de l'application que tu as créée (étape 4) — Client ID et bouton « Afficher » pour le Client secret réapparaissent en haut de cette page.
Utilisés UNE SEULE fois pour créer un utilisateur Powens permanent isolé pour cette organisation — le client secret n'est jamais conservé ensuite. Tu pourras ensuite lier une vraie banque avec tes propres identifiants bancaires, jamais partagés avec Structory.
